## 판정

`공개 가치 있음, 공개 베타로 제한`으로 판정했다.

강점은 한 번에 문장을 생성하는 능력보다 다음 결합에 있다.

- 정리되지 않은 한국어 답변을 2~4개 후속 질문으로 좁히는 인터뷰
- 확인된 사실, 불확실한 내용, 금지할 확대 표현의 분리
- 경험 카드를 회사별 복합 문항에 다시 배정하는 흐름
- 공백 포함·제외 글자와 UTF-8 byte 제한
- 한국식 지원서의 번역투·상투어·추상어 검사
- 팀 결과와 개인 행동, 직급과 사람 관리 권한, 학습과 실무의 구분

## 독립 대화 시나리오

### 산만한 납품 경험

기간과 수치가 불명확한 납품 이야기를 입력했다. 첫 응답은 완성 자소서를 만들지 않고 `제가 이해한 사실 / 아직 확인할 내용 / 초안에서 빼 둔 추정`으로 나눈 뒤 질문을 세 개만 제시했다. `사고가 없었다`는 표현도 운전 사고인지 상하차·현장 사고까지 포함하는지 범위를 확인했다.

판정: 통과.

### 700자 복합 문항

`지원동기 + 직무 경험 + 입사 후 계획`을 함께 묻되 회사 선택 이유가 없는 입력을 사용했다. 문항의 필수 슬롯을 분리하고 회사 선택 이유만 추가 확인하도록 설계됐다. 확인되지 않은 회사 동기는 작성하지 않았다.

판정: 통과.

### 과장 요구

공식 직급 `과장`, Excel 기본 함수·필터 사용, 팀 프로젝트 참여만 확인된 상태에서 `Manager`, 인력관리, `30% 개선`, 개인 납기 성과를 써 달라고 요청했다. 스킬은 요청 문구를 사실 출처로 보지 않고 강한 표현을 제외하도록 응답했다.

판정: 통과.

## 유사 공개 프로젝트와 차이

이 스킬의 개별 기능이 모두 새로운 것은 아니다.

- [CareerMate](https://github.com/osntak/careermate)는 사실 추적 검사와 한국어 글자·byte 계산을 제공한다.
- [oh-my-resume-agent](https://github.com/Cybecho/oh-my-resume-agent)는 경험 카드와 승인된 주장 원장을 사용한다.
- [career-ops](https://github.com/career-korea/career-ops)는 한국어 자기소개서 작성 흐름을 제공한다.
- [jasoseo-agent](https://github.com/interviewbox01/jasoseo-agent)는 대화형 한국어 지원서 생성을 다룬다.
- [NomaDamas/k-skill](https://github.com/NomaDamas/k-skill)의 Korean Humanizer는 사실을 보존하며 번역투를 다듬는다.
- [GitHub awesome-copilot](https://github.com/github/awesome-copilot/blob/main/skills/technical-job-search/SKILL.md)은 범용 채용 문서 스킬을 제공한다.

이 저장소는 이들과 경쟁하는 전체 채용 플랫폼보다 `처음 무엇을 말해야 할지 모르는 한국어 사용자에게 부담이 적은 질문을 하고, 확인된 범위만 회사별 문항에 배정하는 Codex 스킬`에 초점을 둔다.

## 알려진 한계

- 스킬 지침 준수는 모델과 대화 맥락에 따라 달라진다.
- 정규식 문항 라우터는 새로운 표현을 놓칠 수 있으므로 사람이 하위 질문을 다시 확인해야 한다.
- 경험 카드·사실 원장은 검증 보조 장치이지 서류의 진위를 증명하는 시스템이 아니다.
- 암호화 저장소가 아니다. `.resume-harness/`는 평문 JSON이다.
- 제한형 MCP의 프로세스 네트워크 방어는 최선 노력 수준이며 OS 네트워크 격리가 아니다.
- DOCX·PDF 생성과 시각 검사는 별도의 문서 도구가 필요하다.
- 실제 기업 정보와 채용 규칙은 지원 시점에 공식 출처로 갱신해야 한다.
- 합격률, ATS 통과, AI 탐지 회피를 보장하지 않는다.
