# 가상 대화 예시

아래 내용은 실제 지원자의 정보가 아닌 기능 설명용 가상 입력이다.

## 사용자

```text
$resume-application-harness
예전에 식자재 납품을 했고 주 6일 일했어. 바쁠 때도 엄청 많았는데 사고는 한 번도 없었어. 일정이 바뀌면 전화도 하고 순서도 바꾼 것 같아. 책임감 있게 열심히 했지. 이걸 자소서로 써줘.
```

## 첫 응답

```text
지금은 바로 완성문을 만들기보다, 확실히 쓸 수 있는 사실부터 잡겠습니다. 문장으로 정리하지 않아도 되고 기억나지 않으면 `모름`이나 `건너뛰기`라고 답해도 됩니다.

제가 이해한 사실
- 식자재 납품 업무를 했습니다.
- 주 6일 일정으로 근무했습니다.
- 업무가 매우 바쁜 시기가 있었습니다.
- 본인은 책임감을 갖고 일했다고 생각합니다.

아직 확인할 내용
- 근무 기간
- `사고가 한 번도 없었다`의 범위: 업무용 차량 운전 사고인지, 상하차·현장 사고까지 포함하는지
- 일정 변경 때 실제로 본인이 한 행동과 결과

초안에서 빼 둔 추정
- 모든 납품을 지연 없이 마쳤다는 내용
- 고객 연락과 배송 순서를 항상 혼자 결정했다는 내용
- 무사고가 개인의 운전 능력만으로 만들어진 성과라는 설명

쓸 수 있는 키워드·문항
- 반복 업무의 꾸준함
- 일정 변경 대응
- 안전
- 책임감

이번에는 세 가지만 알려 주세요.
1. 이 일은 대략 언제부터 언제까지 했나요?
2. 무사고 기록은 어느 기간의 어떤 사고를 뜻하나요?
3. 일정이 갑자기 바뀐 날 하나를 떠올려, 본인이 실제로 한 행동과 일이 어떻게 끝났는지만 편하게 말해 주세요.
```

## 핵심

첫 차례에 그럴듯한 자기소개서를 완성하지 않는다. 강한 결과의 범위를 확인하고, 기억이 불확실한 행동은 추정에서 제외하며, 사용자가 답할 질문 수를 제한한다.
