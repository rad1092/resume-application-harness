# 자연스러운 한국어 지원서 문체

## 목표

`AI처럼 보이지 않게 꾸미는 것`이 목표가 아니다. 질문에 바로 답하고, 실제 행동과 근거가 보이며, 읽는 사람이 한 번에 이해할 수 있는 한국어를 만든다. 자동 검사는 작성자를 판정하지 않고 번역투·상투어·긴 문장·반복·근거 부족을 경고한다.

## 핵심 원칙

1. 첫 문장에서 질문에 답한다.
2. 한 문항에는 핵심 주장 하나와 이를 입증할 경험 1~2개만 둔다.
3. `성실하다`, `소통을 잘한다`라고 선언하기 전에 실제 행동을 보여준다.
4. 내부적으로 `상황 → 맡은 일 → 판단·행동 → 확인된 결과 → 필요한 경우 직무 연결` 순서를 쓴다.
5. 한 문장에는 핵심 정보 하나만 둔다.
6. 회사 칭찬과 입사 의지보다 선택 이유와 준비 과정을 쓴다.
7. 숫자가 없으면 만들지 않는다. 완료, 기한 준수, 오류 발견, 재작업 방지, 민원 종결, 절차 채택처럼 관찰 가능한 결과를 쓴다.
8. 팀 결과를 개인 성과로 바꾸지 않는다.
9. 면접에서 설명할 수 없는 표현은 쓰지 않는다.
10. 모든 문장을 똑같이 반듯한 문형으로 맞추지 않는다. 사용자가 처음 말한 단어와 판단 이유를 일부 남긴다.

## 주저리 답변을 문장으로 바꾸는 순서

### 1. 원문을 보존한다

원문을 바로 덮어쓰지 않는다. 시기, 역할, 사건, 본인 행동, 다른 사람 행동, 판단 이유, 도구, 결과, 불확실한 부분으로 나눈다.

### 2. 사실 상태를 표시한다

- `확인됨`: 사용자나 자료가 분명히 말했다.
- `표현만 정리`: 사실은 분명하고 말투만 거칠다.
- `의미 확인`: `많이`, `관리`, `좋아졌다`처럼 범위가 모호하다.
- `추정 금지`: 모델이 숫자·기간·직책·성과·감정을 채워야 한다.
- `민감정보`: 문항에 필요하지 않으면 뺀다.

### 3. 사건의 중심을 한 문장으로 정한다

예: `납품 일정이 바뀐 상황에서 안전 기준을 지키며 순서를 다시 정한 경험`.

### 4. 행동 동사로 바꾼다

- `관리를 수행했다` → 무엇을 `확인·기록·조정·보고`했는지 쓴다.
- `소통했다` → 누구에게 무엇을 `질문·설명·공유·설득`했는지 쓴다.
- `기여했다` → 무엇을 `마쳤·줄였·막았·찾았·정리`했는지 쓴다.

### 5. 질문에 필요한 순서로 재배열한다

- 지원동기: 선택 이유 → 관련 경험·준비 → 이 회사·직무와의 구체적 연결
- 직무역량: 할 수 있는 일 → 실제 적용 장면 → 결과·범위
- 협업: 공동 목표 → 역할 차이 → 조정 행동 → 팀 결과와 개인 기여
- 실패: 실패·책임 → 수습 → 재발 방지 → 이후 행동 변화
- 입사 후 계획: 먼저 익힐 일 → 현실적인 단기 역할 → 중기 준비

### 6. 문장을 줄인다

분량을 줄일 때는 다음 순서로 덜어낸다.

1. 일반적인 회사 칭찬
2. 추상적인 서론
3. 같은 뜻의 반복
4. 비슷한 교훈
5. 사건 이해에 불필요한 배경

본인의 행동과 확인된 결과는 마지막까지 남긴다.

### 7. 사용자에게 변경 내역을 짧게 보여준다

- 원문에서 살린 사실
- 삭제한 반복·주변 이야기
- 표현만 바꾼 부분
- 확인되지 않아 넣지 않은 내용
- 최종 글자 수

## 경고 표현과 대체 방식

아래 표현은 금칙어가 아니다. 구체적인 장면 없이 쓰였을 때 경고하고, 먼저 `그 말을 증명하는 장면이 무엇인지` 묻는다. 장면이 있으면 행동으로 바꾸고 없으면 뺀다.

| 경고 표현 | 문제 | 바꾸는 방향 |
|---|---|---|
| `~을 통해` | 행동을 명사로 감춘다 | `교육에서 익혔다`, `대화해 풀었다`처럼 직접 동사 |
| `~을 바탕으로` | 근거가 모호하다 | 무엇을 실제로 참고하거나 적용했는지 |
| `~에 있어서` | 길고 번역투가 되기 쉽다 | `업무에서`, `~할 때`, 주제어로 바로 시작 |
| `~에 의해` | 행동 주체를 감춘다 | 누가 무엇을 했는지 능동문 |
| `~에 대해` | 불필요하게 길 수 있다 | 문맥에 맞게 `~을`, `~에는`, `~와 관련해` |
| `시간·기회를 가졌다` | `have`식 표현 | `논의했다`, `검토했다`, `배웠다` |
| `진행되었습니다` | 주체가 없다 | `제가 진행했습니다`, `팀이 검토했습니다` |
| `이루어졌습니다` | 결과만 있고 행동이 없다 | 바꾼 사람과 행동을 쓴다 |
| `업무를 수행했습니다` | 어떤 일을 했는지 없다 | 실제 동사로 쓴다 |
| `기여했습니다` | 영향 범위가 모호하다 | `줄였습니다`, `마쳤습니다`, `도왔습니다` |
| `역량을 발휘했습니다` | 역량 이름만 반복한다 | 실제 행동을 쓴다 |
| `효율성을 극대화했습니다` | 기준 없는 과장 | 시간·단계·오류의 실제 변화 |
| `성과를 창출했습니다` | 결과가 없다 | 매출·완료·채택·개선 등 확인된 결과 |
| `원활한 소통` | 상투적 자기평가 | 확인·공유·조정한 대상과 정보 |
| `책임감을 가지고` | 태도 선언 | 끝까지 맡은 행동과 일정 관리 방식 |
| `체계적으로` | 절차가 없다 | 체크리스트·순서·기록 방법 |
| `효과적으로` | 효과 기준이 없다 | 전후 차이 또는 관찰 결과 |
| `성공적으로` | 자기평가다 | 완료 상태·피드백·채택 결과 |
| `다양한 경험` | 내용이 없다 | 대표 경험을 구체적으로 열거 |
| `값진 경험` | 무엇이 값진지 없다 | 이후 바뀐 판단이나 행동 |
| `한 단계 성장` | 변화가 불명확하다 | 전에는 못 했고 이후 하게 된 일 |
| `소통의 중요성을 깨달음` | 빈 교훈이 되기 쉽다 | 이후 확인·공유 방식을 어떻게 바꿨는지 |
| `귀사의 발전에 기여` | 어느 회사에도 붙는다 | 지원 직무에서 먼저 맡고 싶은 실제 업무 |
| `회사와 함께 성장` | 막연한 포부 | 배울 업무, 맡을 범위, 확인 방법 |
| `긍정적인 시너지` | 뜻이 모호하다 | 역할 분담·정보 공유·일정 조정 결과 |
| `끊임없는 열정` | 과장된 자기평가 | 지속한 기간과 반복 행동 |
| `준비된 인재` | 근거 없는 자기평가 | 교육·경험·도구 사용 사례 |
| `어떠한 상황에서도` | 검증하기 어렵다 | 실제 경험한 기간·조건으로 제한 |
| `항상·절대·완벽` | 사실 범위를 넘기 쉽다 | 확인 가능한 범위를 명시 |

추가 상투어:

`어려서부터 / 부모님께서는 늘 / 맡은 바 최선을 다하는 / 도전정신을 바탕으로 / 긍정적인 마인드 / 글로벌 인재 / 혁신적인 사고 / 차별화된 경쟁력 / 탁월한 역량 / 무한한 가능성 / 동반 성장 / 귀사의 비전에 깊이 공감 / 시너지를 창출 / 역량을 십분 발휘 / 성장해 왔습니다 / 몸소 깨달았습니다`.

## 문장 구조

### 질문에 답하는 첫 문장

나쁜 시작:

> 급변하는 산업 환경 속에서 기업의 지속 가능한 성장을 위해서는 무엇보다 인재의 역할이 중요하다고 생각합니다.

좋은 시작:

> 현장 기록을 빠뜨리지 않고 남기는 업무가 제가 해 온 점검·납품 업무와 맞아 지원했습니다.

### 한 문장 한 핵심

나쁜 문장:

> 고객의 요구사항을 면밀히 파악하고 팀원들과 적극적으로 소통하여 일정과 품질을 동시에 관리함으로써 프로젝트를 성공적으로 완수할 수 있었습니다.

나눈 문장:

> 고객에게 필요한 결과와 마감일을 다시 확인했습니다. 변경 내용을 팀원별 작업표에 반영했고, 정해진 날에 결과물을 전달했습니다.

### 주체를 분명히 한다

- `처리 시간이 단축되었습니다.` → 누가 무엇을 바꿨는지 확인한다.
- 팀이 한 일은 `팀은`, 본인이 한 일은 `저는` 또는 생략된 주어가 분명하게 쓴다.
- `저는`을 매 문장 반복하지 않는다. 주어가 바뀌거나 혼동될 때만 쓴다.

### 명사보다 동사를 쓴다

- `고객 문의 접수 및 내용 파악, 담당 부서 전달 업무 수행`<br>
  → `고객 문의를 접수해 내용을 확인하고 담당 부서에 전달했습니다.`
- `오류 원인 분석 진행`<br>
  → `오류 기록을 유형별로 나눠 원인을 확인했습니다.`

### 연결어를 줄인다

`또한`, `특히`, `더불어`, `나아가`, `뿐만 아니라`, `그 결과`가 이어지면 문단의 논리보다 접속어로 버티는 글이 된다. 접속어를 빼도 관계가 보이도록 문장 순서를 정한다.

## 전후 예시

예시는 문체 설명용 가상 문장이다. 예시의 사건·성과를 실제 지원자에게 가져다 쓰지 않는다.

### 1. 번역투

- 전: `교육 프로그램을 통해 현장 안전에 대한 이해도를 높일 수 있었습니다.`
- 후: `교육에서 작업 전 점검 항목과 사고 보고 절차를 익혔습니다.`

### 2. 추상적 역량

- 전: `탁월한 의사소통 역량을 바탕으로 팀의 긍정적인 시너지를 창출했습니다.`
- 후: `팀원별 진행 상황을 확인해 남은 일을 다시 나누고, 변경된 마감 일정을 공유했습니다.`

### 3. 책임감 선언

- 전: `맡은 일에 끝까지 책임감을 가지고 최선을 다하는 사람입니다.`
- 후: `담당자가 자리를 비운 날에도 인수인계 내용을 확인해 당일 주문 처리를 마쳤습니다.`

### 4. 주체 없는 피동

- 전: `업무 프로세스 개선에 의해 처리 시간이 단축되었습니다.`
- 후: `반복 입력 항목을 한 표로 합쳐 주문 확인 단계를 줄였습니다.`

### 5. 과장된 성과

- 전: `데이터 기반 의사결정을 통해 업무 효율성을 극대화했습니다.`
- 후: `지난 오류 기록을 유형별로 나눠 자주 틀리는 항목을 먼저 확인했습니다.`

### 6. 상투적 고객 중심

- 전: `고객 중심의 마인드로 고객 만족도 제고에 기여했습니다.`
- 후: `고객이 다시 설명하지 않도록 문의 내용과 처리 상태를 기록해 다음 담당자에게 넘겼습니다.`

### 7. 모호한 협업

- 전: `팀원들과 원활하게 소통하여 프로젝트를 성공적으로 완수했습니다.`
- 후: `서로 다르게 이해한 요구사항을 한 문서로 정리한 뒤 담당자별 수정 범위를 확정했습니다.`

### 8. 빈 성장 서사

- 전: `이 경험을 통해 한 단계 성장하고 소통의 중요성을 몸소 깨달았습니다.`
- 후: `이후에는 일을 시작하기 전에 담당 범위와 마감 시간을 먼저 확인했습니다.`

### 9. 회사 칭찬형 지원동기

- 전: `혁신적인 기술력과 글로벌 비전을 가진 귀사와 함께 성장하고 싶어 지원했습니다.`
- 후: `현장 데이터를 직접 수집하고 검증하는 업무가 제가 해 온 기록·점검 업무와 맞아 지원했습니다.`

### 10. 막연한 포부

- 전: `입사 후 역량을 십분 발휘하여 귀사의 발전에 기여하겠습니다.`
- 후: `입사 초기에는 점검 기준과 보고 절차를 익히고, 이후에는 누락 없이 현장 기록을 남기는 역할을 맡겠습니다.`

### 11. 명사 나열

- 전: `고객 문의 접수 및 내용 파악, 담당 부서 전달, 처리 결과 확인 업무 수행.`
- 후: `고객 문의를 접수해 내용을 확인하고, 담당 부서에 전달한 뒤 처리 결과까지 확인했습니다.`

### 12. `~에 있어서`

- 전: `현장 운영에 있어서 안전은 가장 중요한 가치라고 생각합니다.`
- 후: `현장 운영에서는 안전 기준을 먼저 지켜야 합니다.`

### 13. `가지는`

- 전: `팀원들과 문제 해결 방안을 논의하는 시간을 가졌습니다.`
- 후: `팀원들과 해결 방안을 논의했습니다.`

### 14. 자질 선언

- 전: `저는 성실하고 체계적이며 적극적인 인재입니다.`
- 후: `매일 마감 전에 처리 목록을 다시 확인하고, 누락된 건은 담당자에게 바로 물었습니다.`

### 15. 모호한 문제 해결

- 전: `예상치 못한 어려움에도 포기하지 않고 문제를 성공적으로 해결할 수 있었습니다.`
- 후: `납품 시간이 바뀌자 이동 순서를 다시 정하고 거래처에 도착 예정 시간을 알렸습니다.`

### 16. 빈 교훈

- 전: `많은 것을 배우고 성장할 수 있었던 값진 경험이었습니다.`
- 후: `이 일 이후에는 구두 요청도 바로 기록하고 마감 전에 다시 확인합니다.`

### 17. 팀 성과 확대

- 전: `제가 신규 서비스의 매출을 크게 높였습니다.`
- 후: `팀이 신규 서비스를 출시했고, 저는 고객 문의 유형을 정리해 안내 문구를 수정했습니다.`

### 18. 숙련도 확대

- 전: `Excel을 능숙하게 활용합니다.`
- 후: `Excel에서 기본 함수와 필터를 사용해 주문 내역을 정리했습니다.`

## 검사 기준 해석

결정론적 검사는 검토 시작점이며 오류 판정이 아니다.

### 길이

- 한 문장 90자 이상: 분리 검토
- 한 문장에 쉼표·연결어미가 4개 이상: 절 과다 검토
- 한 문단 350자 이상: 문단 분리 검토
- 세 개 이상의 명사가 조사 없이 이어짐: 명사 나열 검토

### 반복

- 문장 첫머리 `저는/저의/제가`가 3회 이상
- 5문장 중 4문장 이상이 같은 어미로 끝남
- `이를 통해`, `또한`, `특히`, `더불어`, `나아가`, `그 결과` 반복
- 같은 역량어가 한 문항에서 3회 이상

### 사실 경고

- 숫자, 기간, 직책, 매출·시간·오류 개선은 원문과 사용자 확인을 대조한다.
- `항상`, `절대`, `완벽`, `최고`, `어떠한 상황에서도`는 범위를 묻는다.
- `지원·참여·보조`가 `주도·총괄·관리`로 바뀌었는지 확인한다.
- `사용해 봄`이 `전문·숙련·능숙`으로 바뀌었는지 확인한다.

### 문항 적합성

- 지원동기인데 왜 회사·직무인지 없다.
- 협업인데 상대와 조정 행동이 없다.
- 실패인데 책임·원인·이후 변화가 없다.
- 강점인데 근거 사례가 없다.
- 입사 후 포부인데 실제 업무와 실행 순서가 없다.
- 복합 문항의 일부 요구에만 답했다.

## 자동 검사 사용

```powershell
node <skill-dir>\scripts\korean_application.mjs lint --file <draft.txt> --question-file <question.txt> --limit 700 --unit chars
```

검사 결과를 `AI가 쓴 글`이라고 해석하지 않는다. 각 경고에 대해 다음 중 하나를 선택한다.

- 실제 장면을 추가 질문한다.
- 직접 동사로 바꾼다.
- 사실 근거가 없으면 뺀다.
- 문맥상 자연스럽고 필요한 표현이면 유지한다.
