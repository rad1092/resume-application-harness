# Third-party notices

The core Korean skill and its two top-level Node.js scripts use only Node.js built-in modules.

The optional English ATS adapter installs pinned dependencies from `skills/resume-application-harness/scripts/resuml-safe-mcp/package-lock.json`, including:

- [`resuml` 3.2.0](https://github.com/phoinixi/resuml) — ISC
- [`@jsonresume/schema` 1.2.1](https://github.com/jsonresume/resume-schema) — MIT
- [`@modelcontextprotocol/sdk` 1.29.0](https://github.com/modelcontextprotocol/typescript-sdk) — MIT
- [`yaml` 2.8.3](https://github.com/eemeli/yaml) — ISC
- [`zod` 4.3.6](https://github.com/colinhacks/zod) — MIT

Transitive package names, versions, integrity hashes, and declared licenses are recorded in the lockfile. Installed `node_modules` files are not distributed in this repository.
